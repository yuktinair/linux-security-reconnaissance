# Wireshark Network Traffic Analysis

## 1. Objective

To learn how to capture and analyze network packets using Wireshark.

## 2. Tool Used

* Wireshark

## 3. Environment

* Operating System: Kali Linux
* Network Interface: eth0
* Testing Environment: Controlled lab

## 4. Activities Performed

1. Opened Wireshark.
2. Captured network packets on the eth0 interface.
3. Examined captured traffic.
4. Practiced using Wireshark display filters.
5. Saved the packet capture as a PCAPNG file.

## 5. Findings

The initial packet capture recorded 14 packets. The capture was saved for further analysis.

## 6. Security Relevance

Wireshark helps security analysts inspect network traffic, troubleshoot connectivity problems, and investigate potentially suspicious communications.

## 7. Conclusion

This exercise introduced packet capture, basic traffic inspection, and saving network traffic for further analysis.
