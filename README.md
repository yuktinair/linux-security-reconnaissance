
# Linux, Security Tools & Reconnaissance

## About This Project

This repository documents practical cybersecurity exercises completed in a controlled lab environment as part of my cybersecurity learning and internship activities.

## Objectives

* Learn Linux commands, file permissions, and security fundamentals.
* Understand network reconnaissance and enumeration.
* Practice Nmap scanning and service detection.
* Inspect web traffic using Burp Suite.
* Capture and analyze network traffic using Wireshark.
* Explore web application security testing using OWASP ZAP.

## Tools Used

* Kali Linux
* Nmap
* Wireshark
* Burp Suite
* OWASP ZAP
* Python HTTP Server

## Practical Activities

1. Linux fundamentals and file permissions.
2. Network reconnaissance and DNS information gathering.
3. Nmap scanning and service detection.
4. Web traffic inspection using Burp Suite.
5. Network packet capture using Wireshark.
6. Basic local web application testing using OWASP ZAP.

## Scope and Safety

All testing is intended for localhost, systems I own, or environments for which I have explicit authorization. No unauthorized systems are targeted.

## Learning Outcomes

* Improved familiarity with Linux and command-line tools.
* Understanding of basic network reconnaissance.
* Experience capturing and inspecting network traffic.
* Introduction to web application security testing.
* Practice documenting cybersecurity findings.
